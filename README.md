# Производственная практика

Решения трёх кейсов. В каждой папке есть описание работы и Python-скрипт для повторения расчётов.

## Кейс 1. ЭЛМА

Поиск отклонений в заявках на закупку. В итоговом списке 91 строка по 80 заявкам. События после указанной даты среза вынесены отдельно.

- [Описание решения](1кейс_решение/README.md)
- [Список найденных отклонений](1кейс_решение/anomalies.csv)
- [События после среза](1кейс_решение/events_after_cutoff.csv)
- [Код расчёта](1кейс_решение/analyze.py)

## Кейс 2. ЭЛМА

Восстановление процесса закупки по журналу событий. Найдены восемь полных маршрутов и 12 переходов между действиями.

- [Описание решения](2кейс_решение/README.md)
- [Схема процесса](2кейс_решение/scheme.md)
- [Таблица маршрутов](2кейс_решение/variants.csv)
- [Переходы между действиями](2кейс_решение/student_transitions.csv)
- [Код расчёта](2кейс_решение/analyze.py)

## Кейс 3. Синаптик

Проверка двух гипотез по данным подписочного сервиса. Рассмотрены покупки после триала и признаки повторных триалов на одном устройстве.

- [Описание решения и результаты](3кейс_решение/README.md)
- [Код расчёта](3кейс_решение/analyze.py)

## Запуск

Для всех скриптов достаточно Python 3. Порядок загрузки исходных данных и команда запуска указаны в описании каждого кейса.
